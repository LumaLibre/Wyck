The <SourceLink path="worldgen/noise/NoiseRouter.java">NoiseRouter</SourceLink> bundles the
various <SourceLink path="worldgen/function/DensityFunction.java">DensityFunction</SourceLink>s
that create a given dimension's terrain. Where a single density function describes one piece of the
generator's behavior.

## Slots

The eight slots fall into two groups:

- **Climate parameters**: `temperature`, `vegetation`, `continents`, `erosion`, `depth`, and `ridges` describe
the noise fields that bend terrain and feed biome placement.
- **Terrain shape**: `chunkSurfaceLevel` gives an early surface-height estimate, and `finalDensity`
decides whether a given block ends up solid.

The aquifer and fluid functions (`barrier`, `fluidLevelFloodedness`, `fluidLevelSpread`, and `lava`) now live in
<SourceLink path="worldgen/noise/AquiferSettings.java">AquiferSettings</SourceLink>, which is set on the
[noise generator](/worldgen/levels/noise/) with `aquifers(...)`. The old ore vein slots were removed from the router.

:::note

Any slot left unset on the builder defaults to `DensityFunction.zero()`.

:::


### Example Usage
<CodeBlock
    lang="java"
    filename="ExamplePlugin.java"
    code={
`import dev.wyck.worldgen.noise.NoiseRouter;
import dev.wyck.worldgen.function.DensityFunction;
import dev.wyck.worldgen.function.DensityFunctions;
import dev.wyck.worldgen.synth.Noises;
import org.bukkit.plugin.java.JavaPlugin;

public class ExamplePlugin extends JavaPlugin {
    @Override
    public void onEnable() {
        DensityFunction temperature = DensityFunctions.ZERO;
        DensityFunction vegetation = DensityFunctions.ZERO;
        DensityFunction continents = DensityFunction.noise(Noises.CONTINENTALNESS, 0.25, 0.0);
        DensityFunction erosion = DensityFunction.noise(Noises.EROSION, 0.25, 0.0);
        DensityFunction depth = DensityFunction.yClampedGradient(-64, 320, 1.5, -1.5);
        DensityFunction ridges = DensityFunctions.RIDGES;

        // Actual terrain shape
        DensityFunction finalDensity = DensityFunction.yClampedGradient(-64, 320, 1.0, -1.0);

        NoiseRouter router = NoiseRouter.builder()
            // Climate parameters
            .temperature(temperature)
            .vegetation(vegetation)
            .continents(continents)
            .erosion(erosion)
            .depth(depth)
            .ridges(ridges)

            // Terrain shape
            .chunkSurfaceLevel(DensityFunction.constant(0.0))
            .finalDensity(finalDensity)

            // All done!
            .build();
    }
}`}
