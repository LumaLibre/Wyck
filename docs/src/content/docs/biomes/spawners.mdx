:::note

<SourceLink path="biome/entity/MobSpawnSettings.java">MobSpawnSettings</SourceLink> modify server-sided behavior and must be physically set in the world.
This means that this API is not compatible with [`PacketHandlers`](/renderers/packet-handler/).

:::

Wyck provides a built-in system for customizing mob spawns inside custom biomes. <SourceLink path="biome/entity/MobSpawnSettings.java">MobSpawnSettings</SourceLink>, set through the
`NATURAL_MOB_SPAWNS` [environment attribute](/components/environment-attributes/), inform the server what mobs to spawn, how many, how likely, and how many concurrently can spawn.

### Example Usage
<CodeTabs
    examples={[
        {
            label: "Basic",
            filename: "ExamplePlugin.java",
            lang: "java",
            code:
`import dev.wyck.biome.CustomBiome;
import dev.wyck.keys.ResourceKey;
import dev.wyck.biome.entity.MobSpawnSettings;
import dev.wyck.environment.attribute.EnvironmentAttributes;
import org.bukkit.entity.EntityType;
import org.bukkit.plugin.java.JavaPlugin;

public class ExamplePlugin extends JavaPlugin {
    @Override
    public void onEnable() {
        // A biome that will only ever spawn large quantities of pigs.
        MobSpawnSettings spawner = MobSpawnSettings.builder()
            .addSpawn(EntityType.PIG, 100, 4, 12)
            .build();

        CustomBiome.builder()
            .resourceKey(ResourceKey.of("test", "custombiome"))
            .waterColor("#F5F2EB")
            .grassColor("#DBE9EC")
            .attribute(EnvironmentAttributes.NATURAL_MOB_SPAWNS, spawner)
            .register();
    }
}`,
        },

## Mob Spawn Costs

Setting <SourceLink path="biome/entity/MobSpawnCost.java">charge</SourceLink> **lower** and <SourceLink path="biome/entity/MobSpawnCost.java">energyBudget</SourceLink> **higher** allows more of a specific mob to spawn concurrently.

### Example Usage
<CodeBlock
    lang="java"
    filename="ExamplePlugin.java"
    code={`import dev.wyck.biome.CustomBiome;
import dev.wyck.keys.ResourceKey;
import dev.wyck.biome.entity.MobSpawnSettings;
import dev.wyck.environment.attribute.EnvironmentAttributes;
import org.bukkit.entity.EntityType;
import org.bukkit.plugin.java.JavaPlugin;

public class ExamplePlugin extends JavaPlugin {
    @Override
    public void onEnable() {
        MobSpawnSettings spawner = MobSpawnSettings.builder()
            .addSpawn(EntityType.PIG, 100, 4, 12)
            .addSpawn(EntityType.COW, 100, 4, 12)
            // Allows cows to spawn faster in this biome.
            .addMobSpawnCost(EntityType.COW, 25, 100)
            .build();

        CustomBiome.builder()
            .resourceKey(ResourceKey.of("test", "custombiome"))
            .waterColor("#F5F2EB")
            .grassColor("#DBE9EC")
            .attribute(EnvironmentAttributes.NATURAL_MOB_SPAWNS, spawner)
            .register();
    }
}`}
/>
